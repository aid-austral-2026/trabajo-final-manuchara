# El mundo del petróleo: producción y consumo

**Trabajo Final – Análisis Inteligente de Datos**  
**Autor:** Manuel Chara

## Descripción

Este proyecto analiza la evolución de la producción y el consumo mundial de petróleo a partir de datos históricos de distintos países.

El trabajo explora las tendencias globales, compara indicadores per cápita y totales, identifica los principales países productores y consumidores, y estudia los cambios en su participación a lo largo del tiempo.

## Estructura del repositorio

- `index.qmd`: archivo fuente del análisis, desarrollado en Quarto.
- `index.html`: informe final en formato HTML.
- `Data/`: carpeta con los cuatro archivos CSV utilizados.

## Cómo ejecutar el proyecto

1. Clonar o descargar este repositorio.
2. Abrir `index.qmd` en RStudio.
3. Verificar que los cuatro archivos CSV estén dentro de la carpeta `Data/`.
4. Instalar la librería `tidyverse` si aún no está instalada:

   ```r
   install.packages("tidyverse")
   ```

5. Ejecutar **Render** desde RStudio para generar el informe HTML.
